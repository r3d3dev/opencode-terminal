This is what the `downloads` badge in the README shows. The badge renders
`downloads.json`, which sits next to this file; both are regenerated by
[the downloads workflow](https://github.com/r3d3dev/opencode-terminal/blob/main/.github/workflows/downloads.yml),
daily or on demand. Only downloads are counted, never installs, so the sources
are added like for like. A release package counts every fetch of the file,
including the ones this project makes while checking a release, so that row
runs slightly ahead of the real user count. The page is rewritten when a count
moves and left alone otherwise.
